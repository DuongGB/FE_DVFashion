## 📌 Project Overview

**FE_DVFashion** is the frontend for the DVFashion e-commerce platform, built with **ReactJS** and **Vite**.

### 🎯 Goals

- Create a modern, user-friendly fashion e-commerce website.
- Provide essential features: product browsing, searching, filtering, ordering.
- Optimize user experience for both desktop and mobile.

---

## 🛠 Technologies Used

- **Frontend Framework:** [ReactJS 19](https://react.dev/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **UI Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Routing:** [React Router DOM](https://reactrouter.com/)
- **API Calls:** [Axios](https://axios-http.com/)
- **State Management:** [TanStack React Query](https://tanstack.com/query/latest)

---

## 🚀 Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start development server:**
   ```sh
   npm run dev
   ```
3. **Build for production:**
   ```sh
   npm run build
   ```
4. **Preview production build:**
   ```sh
   npm run preview
   ```

## 📌 Project Overview
**FE_DVFashion** is the frontend of the DVFashion e-commerce system, built with **ReactJS + Vite**.  
Project goals:
- Build a modern, user-friendly fashion e-commerce website.
- Support essential features such as product browsing, searching, filtering, and ordering.
- Optimize the user experience for both desktop and mobile devices.

---

## 🛠 Technologies Used
- **Frontend Framework:** [ReactJS 18](https://react.dev/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **Supporting Libraries:**  
  - [React Router DOM](https://reactrouter.com/) – Routing management.
  - [Axios](https://axios-http.com/) – API calls.
  - [Tailwind CSS](https://tailwindcss.com/) – Fast UI styling.
